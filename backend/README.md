# Backend

Maven aggregator with one Quarkus module per service. There is no shared module (decision A9).
Conventions: [docs/plan/01-conventions.md](../docs/plan/01-conventions.md).

| Module | Dev port (`quarkus:dev`) | Container |
|---|---|---|
| auth | 8081 | `https://auth:8443` |
| players | 8082 | `https://players:8443` |
| monsters | 8083 | `https://monsters:8443` |
| teams | 8084 | `https://teams:8443` |
| encounters | 8085 | `https://encounters:8443` |
| history | 8086 | `https://history:8443` |

```bash
mvn verify                       # build and test every module (needs Docker for Dev Services)
mvn -pl auth verify              # one module
mvn -pl players quarkus:dev      # dev mode: plain HTTP, throw-away PostgreSQL, live reload
```

## Profiles

| Profile | Used by | Database | TLS | Secrets |
|---|---|---|---|---|
| `dev` | `quarkus:dev` | Dev Services | no | fixed dev-only values in `application.properties` |
| `test` | `mvn verify` | Dev Services | no | fixed test-only values; `auth` tests generate a throw-away JWT key pair |
| `prod` | containers | `<svc>-db` with `sslmode=verify-full` | yes, port 8443 | `/run/secrets` (generated by `infra/init-secrets`) |

## Copied code (commons)

Every service contains the same cross-cutting classes. The reference copy is in `players`:

| Class | Services | Purpose |
|---|---|---|
| `error/ApiException`, `ErrorCodes`, `ErrorResponse`, `ErrorDetail`, `ExceptionMappers` | all | common error format `{error, message, details}` |
| `security/CurrentPlayer` | all | `player_id` from the JWT `sub` |
| `security/RequestIdFilter` | all | `X-Request-Id` in logs and responses |
| `security/ServiceTokenProvider`, `ServiceTokenFilter`, `client/AuthClient`, `client/TokenResponse` | players, teams, encounters (services that call others) | service token (client credentials), added to internal REST clients |

`auth` does not use `ServiceTokenProvider`: it signs its own service token (`security/LocalServiceTokenFilter`).

To add the commons to a service (or propagate a change), copy the files from `players` and fix the package:

```bash
for f in error/*.java security/CurrentPlayer.java security/RequestIdFilter.java; do
  sed 's/tamer\.players/tamer.<svc>/g' players/src/main/java/it/unipi/ase/tamer/players/$f \
    > <svc>/src/main/java/it/unipi/ase/tamer/<svc>/$f
done
```

A change to a copied class must be applied to every copy in the same pull request.
`players/src/test/.../security/CommonsTest` verifies the behaviour (error format, roles, request id).

## Internal REST clients

```java
@RegisterRestClient(configKey = "monsters")
@RegisterProvider(ServiceTokenFilter.class)       // never on AuthClient
@Path("/internal/monsters")
public interface MonstersClient {
    @GET
    @Timeout(2000)
    @Retry(maxRetries = 2, delay = 200)           // only on idempotent calls
    @CircuitBreaker(requestVolumeThreshold = 10, failureRatio = 0.5, delay = 5000)
    List<MonsterSummary> byRarity(@QueryParam("rarity") String rarity);
}
```

```properties
quarkus.rest-client.monsters.url=${TAMER_MONSTERS_URL:http://localhost:8083}
%prod.quarkus.rest-client.monsters.tls-configuration-name=internal
```

Wrap client failures in `ApiException.dependencyUnavailable(e)`, or let them reach `ExceptionMappers` (mapped to `503 DEPENDENCY_UNAVAILABLE`).
In `@QuarkusTest`, mock the client with `@InjectMock @RestClient`.
